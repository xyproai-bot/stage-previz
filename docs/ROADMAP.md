## 0. 錯誤與安全（進行中）
- 後台權限：每條 /api/projects/:id/... 檢查專案成員＋專案角色；歌/cue SQL 一律帶 project_id；封存專案禁止寫入。
- 留言搬到 D1 comments 表（KV 讀改寫會掉資料）＋身分檢查。
- 歌曲狀態轉換規則＋409 樂觀鎖（舊畫面撤回會蓋掉導演決定）。
- 分享密碼：CORS 允許 x-share-password（正式站目前解不開）、密碼加鹽雜湊、影片用短效簽章。
- 分享頁 cue 擺位與導演頁同一套「沿用上一個 cue」算法。
- 封存專案「還原」出錯；換模型「清除物件」會刪掉所有 cue 位置 → 要確認。
- 編輯器：機關位移重複套用、轉場 0＝直接切（舊資料 0→1 遷移）、縮放工具不存、復原跨 cue、載入中誤顯示、數字欄 Enter 存。
- 3D 檢視設定：拿掉本機快取回填（會把別台電腦的舊值寫回）。

## 1. 影片上 LED ＋「＋加影片」
- 導演頁、分享頁：選哪一版，LED 就播哪一版，cue 跟影片時間走（沿用分享頁本地檔案那套）；平面播放器縮成小窗。
- 每首歌「＋加影片」：拖檔上傳到 R2（分段上傳、進度條）、貼連結（Drive 單檔 / Dropbox / OneDrive / 直接網址，後台複製一份到 R2）、本機檔案（工作站、導演頁也有）。
- 版本號固定（V1、V2…，誰交的、何時、一句說明）；不再依修改時間排序。
- Drive 資料夾同步：改用歌曲固定代號對應（不再依歌單第幾首），只收影片檔，對不到的進「未分類」。
- 大陸：影片從 R2 播（不經 Google），模型與影片快取設定。

## 2. 審片與角色連動
- 登入後依角色進對的頁面；拿掉首頁 demo 角色卡；邀請連結（點了就登入進專案）＋可貼 LINE/微信的說明文字。
- 前端路由權限（/admin 只給 admin）；專案角色生效。
- 歌曲指派給動畫師（編輯器可指派）；「我的」清單才有內容。
- 狀態與留言自動更新（20–30 秒＋切回分頁時）；通過/需修改綁版本、需修改要寫原因；有新版標記。
- 站內通知收件匣（@我、被退、新版待審、被指派）；@中文名字修正；提交審查的提示文案講真話。
- 留言綁版本、可回覆、「已改好（V3）」。
- 提案（proposal）流程：補齊「接受」或先拿掉介面。
- 時間顯示時區（UTC→本地，差 8 小時）。
- 導演頁：沒有 cue 也顯示舞台；有影片時 cue 列被推出畫面；切歌閃舊 cue；切歌後舊留言被當新的跳出。

## 3. 機關系統
- 每個機關設定一次：哪些物件（可成組）、方向、行程範圍、速度、常用位置（收起/半開/全開）。
- 每個 cue 存自己的機關位置（現在全專案共用一組）；滑桿鎖在行程內；沿用上一個 cue。
- 速度檢查（轉場比機械快就提醒、一鍵照機械速度）；機關總表匯出（PDF/Excel）；碰撞標示（之後）。

## 4. UI 打磨
- 全站換掉 emoji：一套線條圖示（Icon 元件）＋必要時只用文字。
- 用詞統一（待製作/審查中/需修改/已通過；製作/動畫師/導演；轉場秒數；模型庫；常用擺位…）。
- cue 編輯順手度（插入、行內改名、⋯選單、快捷鍵、沿用標示）；物件命名引導；完成度清單。
- 手機/iPad（導演頁清單化、上一首/下一首、按鈕收進⋯）；空狀態與錯誤提示；alert/prompt 換成畫面內對話框。
- 說明書擴充到全部角色；LED 對位圖下載；LED 等待畫面換成測試圖。
