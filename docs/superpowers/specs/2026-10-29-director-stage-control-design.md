# 導演「調整舞台」模式 + 弧形軌道

日期：2026-10-29　狀態：用戶看過 3D 草圖、說「其他都很棒」，等用戶看完這份規格才開工

## 1. 要解決什麼

機關的造型（LED 怎麼排、怎麼轉、平台升多高）是導演決定的，但現在只有製作能在編輯頁改機關位置。
導演要能在導演頁自己調、直接改 Cue 庫，而且導演不是做設計的，畫面要直覺：點物件 → 出現把手 → 拖。

另外旋轉 LED 的「橫移」現在是一直線左右走；實際上它掛在天上的弧形軌道，越往左右越靠近觀眾，也會跟著軌道轉角度。

## 2. 已經跟用戶確定的事

- 旋轉 LED 橫移改成沿弧形軌道走，**走的時候跟著軌道轉角度**；自己的「旋轉」照舊疊在上面。
- 「側面的 LED」= 兩對對開門。它們本來就繞同一個圓心轉，已經是沿弧線走、會跟著轉角度。
- **四片門要各自獨立動，不能聯動**（10-29 用戶說）。現在是兩個「對開」機關、一個帶兩片對稱動 → 要拆成四個各自的機關（見 3.4）。
- 6 片旋轉 LED 到對開門轉軸的水平距離都一樣（差不到半公分），所以弧形軌道就用對開門同一個圓心。
- 導演除了機關位置，還能：改轉場秒數、從現有 cue 複製一個新的、改名。**物件顯示 / 隱藏先不開。**
- 導演存回 Cue 庫後，要通知：這個專案的製作 + 用到這個 cue 的歌的動畫師。
- 只做預覽：機關照設定的時間動，不做「速度來不及」之類的現場工程警告。
- 畫面照 3D 草圖（`director-adjust-stage-mockup.html`，對話裡給過）；草圖裡門 / 平台 / 提詞 LED 的位置是示意，正式版用專案自己的模型，位置一定是對的。

## 3. 第 1 部分：弧形軌道（新的機關變化）

### 3.1 定義

直線機關多一種變化 `variant = 'arc'`（沿弧形軌道）：

| 欄位 | 意思 |
|---|---|
| `pivot` | 軌道圓心（場景單位，跟旋轉機關的轉軸中心一樣） |
| `axis` | 轉軸方向（通常是垂直）；正負決定「值變大往哪邊走」 |
| `arcRadius`（新欄位，公尺） | 物件到圓心的水平距離 |
| 行程、預設、常用位置 | 跟一般直線機關一樣，**單位還是公尺（沿著弧線量）** |

算法：值 s 公尺 → 角度 θ = s ÷ 半徑（弧度）→ 物件繞圓心轉 θ。
所以物件沿著圓走、面向也跟著轉（就是「跟著軌道轉角度」）。裝在它下面的機關（旋轉 LED 的自轉）照舊先套，再一起被帶著走。

- 值的意思不變（沿軌道走幾公尺），舊 cue 存的數字不用改；只是位置從直線變成弧線（越外面越靠近觀眾）。
- 半徑 0 或沒填 → 當成一般直線機關（不會壞掉）。
- 「從 3D 拖完存回去」的還原（`basePoseFromScene`）照旋轉機關的方法反過來，不會跳。

### 3.2 設定畫面（編輯頁「設定機關」）

- 直線機關多一個選項「移動方式：直線 / 沿弧形軌道」。
- 選弧形後：圓心可以「跟某個旋轉 / 對開機關同一個圓心」直接挑，或自己打；半徑有一顆「照物件現在的位置算」。
- 3D 畫面的行程線畫成弧線（現在是直線）。
- 匯出 / 匯入 / 複製專案 / 備份都要帶新欄位。

### 3.3 套到第一個真實案子

- 把 6 個旋轉 LED 的「橫移」改成弧形，圓心用對開門的轉軸。
- **這一步會改正在用的專案的機關，動手前再問用戶一次**；先備份，改之前 / 之後各截一張 cue 29、30、30-1、31 的圖給用戶比。
- 這個案子的實際數字放在案子資料夾，不放進程式庫。

### 3.4 把「對開」拆成兩個各自動的機關

設定機關裡，對開機關多一顆「拆成兩個各自動的機關」：

- A 邊留在原本的機關（id 不變，變成一般旋轉 / 直線機關）；B 邊變成一個新機關（方向 / 轉軸中心用原本 mirror 的），
  名字預設「原名 A」「原名 B」（可以改）。行程、常用位置、最快速度、裝在哪個機關上都照抄。
- 每個 cue 存的位置（Cue 庫的 cue、每首歌的 cue、提案）都抄一份給 B 邊，數字一樣 → **拆完每個 cue 的畫面一模一樣**。
- 一次做完（要嘛全拆好，要嘛都沒動），記在活動紀錄裡。拆完不能一鍵合回去（要合就自己重設）。
- 套到第一個真實案子：兩對對開門拆成四個機關。**一樣先備份、拆之前 / 之後截 cue 29、30、30-1、31 的圖給用戶比。**

## 4. 第 2 部分：導演頁「調整舞台」模式（先只預覽，不存）

### 4.1 誰看得到

導演頁上方多一個切換「審片 / 調整舞台」。導演、這個專案的製作、全站製作看得到；動畫師、分享連結的訪客看不到。
專案不是 Cue 庫模式的話，不出現這個切換。

### 4.2 畫面

- 左邊：3D 舞台（跟審片一樣的模型和 LED 畫面）。上面一排 cue 可以切換。
- **選東西**：在 3D 點物件，或從右邊「清單」挑。選到的物件發亮，原本存的位置留一個虛線框。
- **把手**（綠色，拖得動）：
  - 弧形軌道 / 對開門：軌道上的把手，左右拖。**四片門各自一個把手、各自動**；要一起動就用「整組選」一次選好幾片。
  - 自轉：地上一個圈，拖圈上的點。
  - 升降、緞帶：上下箭頭。
  - 吊掛（提詞 LED）：每個吊點一個上下把手，預設「左右一起」，取消就能單調一邊讓它斜。選到時畫面自動轉過去。
- **右邊面板**：選到的機關的常用位置按鈕 + 滑桿 + 數字；拖的時候自動對齊常用位置和 0.1 公尺，按住 Alt 不對齊。
- **整組選**：同一排機關（現有的「一排機關」）可以「整排一起」，另外照位置分「左半 / 右半」。整組動時是一起加同樣的量。
- **自轉方向**：180° 和 −180° 畫面一樣、轉的方向不同，面板直接寫「從上一個 cue 轉過來：從上面看逆時針轉半圈」；
  「播轉場」從上一個 cue 用轉場秒數播一次。
- **看的角度**：觀眾看 / 正上方 / 側面。
- 跟著軌道走時，面板寫「往觀眾靠近幾公尺、轉幾度」，導演不用自己算。
- 改過的機關在清單上標顏色。

### 4.3 沒存就離開

切 cue、切回審片、換歌、關頁面時，如果有改了沒存 → 問「放棄這些改動？」。

## 5. 第 3 部分：存起來

改了東西後，下面出現黃色提示列：「改了 N 個機關」＋三顆按鈕。

### 5.1 存回 Cue 庫

- 按下去先列出「這些歌會一起變：S05、S12、S17」，再按確定。
- 只寫機關位置（物件的位置 / 顯示隱藏一個都不動）。
- 存的時候檢查「剛剛有沒有別人改過」；有 → 告訴導演「這個 cue 剛剛被 ○○ 改過」，可以重新載入再改。
- 存完跳一則「已存」＋「復原」（用後台回傳的上一版）。
- 通知：這個專案的製作 + 用到這個 cue 的歌的動畫師（不通知自己）。
  通知寫「導演 ○○ 改了 cue 30 的舞台（S05、S12、S17 會一起變）」，點了開那首歌。

### 5.2 另存成新 cue

- 打名字（預設「原名（導演改）」），編號自動給下一個（例如 30-2）。
- 只把**這首歌的這個 cue** 換成新的；其他歌照舊用原本的 cue。新 cue 的物件設定照抄原本的。
- 一樣通知製作和這首歌的動畫師。

### 5.3 複製、改名、轉場秒數

- 複製：從現有 cue 複製一個新的放進 Cue 庫（還沒放進任何歌）。
- 改名：只改名字，不改編號。
- 轉場秒數：改的是 Cue 庫的秒數（用到的歌都一起變，一樣先列出受影響的歌）；
  如果這首歌的這個 cue 自己另外設了秒數，畫面寫「這首歌自己設了 X 秒」，改的是這首歌自己的。

## 6. 權限（放寬導演的權限，用戶要點頭）

導演**可以**：

- 改 Cue 庫 cue 的機關位置（一次整份換掉，帶「剛剛有沒有人改過」的檢查）
- 從現有 cue 複製 / 另存成新 cue（只能改機關位置；物件設定照抄來源）
- 改 Cue 庫 cue 的名字、轉場秒數；改這首歌的 cue 自己的轉場秒數

導演**還是不能**：物件顯示 / 隱藏 / 位置、刪 cue、改編號、設定機關、模型、版型、歌單、cue 的時間點。

後台做法：多一種權限需求「導演改舞台」（製作或導演先放行），每個 handler 再檢查只動了允許的欄位；
機關位置走一條新的「只換機關位置」的路，不讓導演用「整個畫面一次換掉」那條。
每一條都要有測試對到後台真的擋（跟 `members.test.mjs` 一樣的寫法），成員面板的導演說明也一起改。

## 7. 不做的事

- 物件顯示 / 隱藏、刪 cue（之後再說）
- 現場工程警告（速度、碰撞）
- 改 LED 的畫面、顏色
- 分享連結的訪客調整舞台

## 8. 測試和驗收

- 弧形算法：值 0 不動；值 s 在圓上、到圓心距離不變、面向轉 s ÷ 半徑；正負方向；跟自轉疊在一起；拖完還原不跳。
- 權限：導演能做的每一條會過、不能做的每一條被擋（含想偷改物件設定）。
- 衝突：兩個人同時存 → 後存的拿到「剛剛被改過」。
- 通知：收的人對（製作 + 用到的歌的動畫師，不含自己）。
- 每個階段在測試站用真的瀏覽器從頭點一遍（導演帳號），截圖給用戶。

## 9. 分階段上線

1. **弧形軌道 + 拆開對開**：機關多一種變化 + 設定畫面 + 行程線；對開機關可以拆成兩個 → 上線 → 套到案子（6 個橫移改弧形、兩對門拆成四個；前後截圖）。
2. **調整舞台（只預覽）**：模式切換、把手、面板、整組、播轉場、看的角度；不能存。
3. **存起來**：存回 / 另存 / 復原 / 衝突檢查 / 通知 / 複製 / 改名 / 秒數 / 導演權限。

每個階段：先備份資料庫 → 測過 → 直接上正式（10-23 的規矩）。
