# 動畫師上手教學（設計）

日期：2026-10-30｜用戶已逐段同意（形式、練習地點、影片聲音、做法兩段、卡住找誰）

## 為什麼要做

動畫師裡有人對新東西排斥。說明頁（/help）是「查資料用」的，完整但字多；排斥的人不會自己去看。
所以教學的原則是：

- **先講「你的 AE 做法不用改」**：這裡只是多一個把動畫貼到真舞台上看的地方；幫你省的是跑現場、來回改、傳檔案。
- **先讓他成功一次**：第一次只教到「看到自己的動畫貼在舞台上」，五分鐘內做到；其他的用到再看。
- **少字多畫面**：每一步一到三句話＋一段 10～20 秒的短片（沒聲音、循環播放）。
- **不會卡死、不會闖禍**：每一步都能「下一步」「跳過」；帶著做的時候不會真的交影片給導演。
- **卡住了找誰**：找這個專案的製作（工作站裡直接寫名字）。

## 要做的三樣東西

### A. 工作站「帶著做」（第一次進工作站自動出現）

- **誰會看到**：在工作站裡、身分是動畫師的人，第一次打開 /studio/:projectId 時自動出現。製作用「用動畫師的畫面看」時不自動跳（可以手動叫出來檢查）。
- **記得看過了**：記在這台電腦的瀏覽器（localStorage，鍵名帶版本號，例 `sp_tour_animator_v1`）。不動後台、不動資料庫。換電腦會再出現一次，一鍵跳過。之後步驟大改就換版本號，讓大家再看一次。
- **再叫出來**：上方列「使用說明」旁邊（窄畫面收在「⋯」裡）加「帶我走一遍」。
- **長相**：其他地方變暗，只亮要看的那個按鈕或區域，旁邊一個說明框（標題、一兩句話、第幾步／共幾步、上一步、下一步、跳過）。Esc＝跳過。不用 emoji、不用原生對話框、繁中、圖示用 `<Icon/>`。
- **要看的東西找不到時**（窄畫面被收進「⋯」、這首歌沒有那個按鈕）：說明框放畫面中間，文字改成告訴他在哪裡（例：「在右上角『⋯』裡」），不會卡住。
- **步驟**（大約 5 分鐘）：
  1. 歡迎：你在 AE 裡的做法一點都不用改，這裡是把動畫貼到真舞台上看的地方。（不亮任何東西）
  2. 這是你的歌：亮歌曲清單的「我的」。
  3. 轉轉看舞台：亮 3D 畫面，拖拉轉、滾輪縮放、轉亂了按「重置攝影機」。他拖一下就自動往下（也可以直接按下一步）。
  4. LED 上的測試圖：每塊 LED 的名字和位置，跟你 AE 合成裡的一樣。（LED 沒畫面時本來就會顯示測試圖；這首歌已經有影片的話，文字改成「沒放東西的時候 LED 會顯示測試圖」）
  5. 把你的動畫放上去：亮「本地檔案」。把一支 AE 輸出的影片拖進來，不會上傳、別人看不到。放上去之後說明框變成「成功了」。（可以按下一步跳過）
  6. 播放、點 cue：亮小播放器和 cue 列；點 cue 影片跳到那個時間。
  7. 之後要用的（只指位置，不按）：「＋ 加影片」＝給導演看的時候；「AE 即時」＝AE 一動 LED 就跟著動，要先裝兩個小程式；「錄成影片」＝錄下來直接傳給導演。
  8. 卡住了：按「?」、看上手教學頁，或找這個專案的製作「<製作名字>」（從專案成員裡角色是製作的人；找不到就寫「邀請你進來的製作」）。最後一個按鈕「打開上手教學」。
- **程式放哪**：步驟內容和規則（哪些步驟、找不到目標時的文字、製作名字怎麼組）放純函式檔，好測；畫面元件另一個檔；工作站只加掛載點和要亮的地方的標記（`data-tour="..."`）。

### B. 網站上的教學頁「動畫師上手教學」

- **網址**：`/tutorial/animator`，不用登入就能看（跟 /help 一樣）。
- **內容**（照做一首歌的順序；每步一到三句話＋一個畫面位置；每段最後「想知道更多」連到說明頁那一段）：
  1. 先看這裡（1 分鐘）：這是什麼、幫你省什麼、你的 AE 做法不用改。最上面放教學影片的位置。
  2. 第一次登入：邀請連結、登入碼、找到「我的歌」。
  3. 開工前：拿 LED 對位圖，或用 AE 腳本一鍵建合成（畫布大小對了 LED 才對得準）。
  4. 做的時候在舞台上看：本地檔案 → AE 即時（第一次設定、每次使用）→ 用測試圖檢查對位 → 沒影片的歌聽音樂、看 cue 時間對拍子。
  5. 交一版：AE 輸出設定 → 加影片 → 提交審查。
  6. 錄成影片給導演（好好教：解析度、範圍、視角、cue 字幕、存到哪裡、可以直接傳 Google Drive）。
  7. 導演有意見時：看意見（點留言飛到那個視角）→ 回覆 → 改好了 → 比較兩版。
  8. 卡住了：最常見的五種（LED 一片黑、對不準、上傳斷掉、瀏覽器擋住、Safari 不能用）各給一個照做的解法；還不行找邀請你進來的製作。
- **畫面位置**：第一階段先放現有的說明頁截圖（web/public/help/animator、win），沒有的先用文字框；第二階段換成短片。短片：`<video muted autoplay loop playsinline>`＋第一格當封面；使用者設了「減少動態」就不自動播、給播放鍵。字幕不燒進短片，用網頁文字（之後改字不用重錄）。
- **連過來的地方**：說明頁動畫師章節最上面一條「第一次用？看上手教學」、工作站上方列選單「上手教學」、帶著做的最後一步。
- **規則**：繁中、不用 emoji、畫面不出現英文角色字（守門測試會擋）、手機寬度不左右捲動。

### C. 短片和教學影片

- **在哪裡拍**：全部在本機測試環境（本機後台＋本機資料庫＋本機網站、假帳號），正式站資料完全不碰。
- **示範舞台**：我們自己做的簡單舞台（主 LED、兩側 LED、地板、一個升降台），不用 repo 裡的 stage.glb（來源不確定），絕不用任何客戶的模型或檔案。示範動畫也自己做（彩色、看得出 LED 對位）。
- **網站片段**：用自動瀏覽器照步驟錄，錄的腳本存進 repo，網站改了可以重錄。
- **AE 片段**：在用戶電腦上用電腦操作開 AE 2026 的新空專案錄：跑 AE 腳本建合成、打開 NDI 輸出、輸出設定、AE 一動 LED 跟著動。錄之前請用戶關掉不該入鏡的視窗；錄的時候用戶不要動滑鼠。只開假的專案。
- **短片規格**：每段 10～20 秒、沒聲音、循環、檔案小（放 web/public/help/tutorial/）。
- **教學影片**：3～5 分鐘、只有字幕（字幕燒進影片）、1920×1080 mp4；前面「為什麼要用」，中間同一批片段，最後「卡住找誰」。檔案盡量壓在 25 MB 以下（網站單檔上限）；壓不下來再跟用戶討論放哪。成品也直接給用戶傳 LINE。

## 順序

1. 帶著做＋教學頁（畫面先用截圖）→ 自己試過 → 上線（只改網站）。
2. 錄網站和 AE 短片 → 換掉截圖 → 上線。
3. 剪教學影片 → 給用戶、放到教學頁 → 上線。

每一步做完跟用戶報告。

## 不做

一頁小抄 PDF、共用練習專案、後台記錄看過教學、配音（AI 或真人）。

## 驗證

- 帶著做的規則：純函式測試（步驟順序、找不到目標時的文字、製作名字、看過就不再自動跳、製作用動畫師畫面看不自動跳）。
- 教學頁：渲染測試、所有「想知道更多」連到存在的說明頁段落、守門測試（英文角色字、emoji）。
- 全部 vitest 一次、build。
- 瀏覽器實測一次：1280 寬和手機寬，帶著做從頭走到尾、教學頁捲到底沒有左右捲動。
- 前後台共用的規則檔不動（這次只改網站）。
